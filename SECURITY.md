# Security Policy

## Supported Versions

Actively supported and provided security updates for the following versions of the Lair of Xaldern engine:

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |
| < 0.1.0 | ❌        |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, **please do not open a public issue.** Instead, please report it directly to the project lead:

* **Contact:** mr.dom.barbero@gmail.com
* **Expected Response Time:** I will aim to respond to all security reports within 48-72 hours.

Please include a detailed description of the vulnerability and, if possible, steps to reproduce it. Once a fix is ready, we will credit the reporter in the release notes unless they prefer to remain anonymous.
