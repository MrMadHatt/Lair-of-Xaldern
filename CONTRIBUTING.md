# Contributing to Lair of Xaldern

First off, thank you for wanting to help build the Lair! To keep the engine stable and the lore consistent, please follow these guidelines.

## How Can I Contribute?

### Reporting Bugs
* Check the **Issues** tab to see if the bug has already been reported.
* If not, open a new issue. Include your Python version and the steps to reproduce the error.

### Suggesting Enhancements
* We welcome new engine features (like new commands or combat logic).
* Please open an issue first to discuss the idea before writing the code.

### Pull Requests (PRs)
1. **Fork the repo** and create your branch from `main`.
2. **Stick to the style:** Use PEP 8 standards for Python.
3. **Modular Logic:** Keep engine logic separate from world data.
4. **Test your code:** Ensure `main.py` runs without errors before submitting.

---

## Lore vs. Engine
* **The Engine (Public):** We accept contributions for Python logic, UI improvements, and bug fixes.
* **The Lore (Private):** At this time, the core story and world data of Xaldern remain a solo project. Contributions to `world.json` structures are welcome, but the narrative is handled by the project lead.

## Ground Rules
By contributing, you agree to abide by our **Code of Conduct**.
